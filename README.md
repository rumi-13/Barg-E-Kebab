# Barg-e-Kebab 🍢 | Responsive Restaurant Landing Page  

A **static, responsive landing page** for a restaurant named **Barg-e-Kebab**, built using **HTML, Tailwind CSS, and a bit of JavaScript**.  

## 🚀 Features  
✅ Fully responsive design  
✅ Modern UI with Tailwind CSS  
✅ Interactive elements using JavaScript  
✅ Fast and lightweight
